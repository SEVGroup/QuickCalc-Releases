# QuickCalc

**A lightweight, minimal calculator for macOS.**

QuickCalc is a free, easy-to-use calculator designed for quick everyday calculations.

---

## 📥 Installation

1. Download the latest `.dmg` file from [GitHub Releases](https://github.com/SEVGroup/QuickCalc-Releases/releases).
2. Open the downloaded `.dmg` file.
3. Drag **QuickCalc** into your **Applications** folder.
4. Launch QuickCalc from Applications.

## 🔐 macOS Security Warning

QuickCalc is not yet notarized by Apple. macOS may display a security warning when you first launch the app.

**If macOS blocks QuickCalc:**

1. Try opening QuickCalc normally.
2. Open **System Settings → Privacy & Security**.
3. Scroll down to the **Security** section.
4. Find the message about QuickCalc and click **Open Anyway**.
5. Enter your Mac password if prompted.
6. Confirm by clicking **Open**.

**You only need to do this once.**
